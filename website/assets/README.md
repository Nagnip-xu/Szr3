# Asset origins

- avatar-001, avatar-002, avatar-003: derived from existing project preset reference videos at api/storage/presets/defaults. Videos are nine-second, muted previews encoded at 540×960; WebP posters are extracted at one second. These depict preset reference material and are not evidence of a newly generated output.
- fonts/bricolage-grotesque-*.woff2: Google Fonts, Bricolage Grotesque, SIL Open Font License. Downloaded using Impeccable font-fetch.
- fonts/xinggui-sc.woff2: Google Fonts, Noto Sans SC variable font, subset of characters actually used in the page and interaction copy. SIL Open Font License. Regenerate using tools/fetch-font.mjs after Chinese copy changes.
- mark.svg: original geometric orbit mark, drawn as SVG for this website, inspired by the existing product's orbit logo language.

Font license texts are included in the fonts directory. Raster provenance is retained in the matching WebP JSON sidecars.
