完全不会剪辑，也能开始吗？

可以从文案、配音、数字人、后期逐步开始。工作台将这些环节放在同一条流程中，你可以在成片前预览和调整内容。最终效果仍会受文案、参考素材与所选参数影响。

可以使用自己的形象和声音吗？

支持上传有授权的参考视频和音频，保存自定义数字人与音色。使用前需要完成相应的肖像、声音使用授权确认。

官网上的互动会实时生成数字人吗？

这里展示现有预设人物的参考片段，你可以切换人物、编辑文字并预览字幕样式。正式配音、口型驱动和视频生成，需要在星轨工作台中完成。

完成的视频如何导出和发布？

完成后可导出 MP4 文件，并自行上传到你使用的内容平台。当前产品尚未接入多平台自动发布功能。

在哪里了解项目与运行方式？

前往 GitHub 仓库，查看功能说明、环境要求和运行指南。遇到问题或有新想法，也可以通过 Issues 与我们交流。
