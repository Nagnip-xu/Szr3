# 星轨数字人官网

独立静态官网，以产品介绍、参考演示和 GitHub 项目入口为主。所有资源位于本目录，浏览不依赖 API、数据库或 GPU。

**在线访问：<https://nagnip-xu.github.io/Szr3/>**  
**源码仓库：<https://github.com/Nagnip-xu/Szr3>**

## 本地预览

需要 Node.js 20.9+，无需安装任何 npm 依赖：

```powershell
# 在项目根目录
npm run dev:website
```

访问 <http://127.0.0.1:4175>。端口占用时可在本目录运行 `npm run dev -- --port 4176`。也可使用任意静态 HTTP 服务，请勿直接用 file 协议打开模块脚本。

## 交互与内容

- 首屏人物组合的单次进场、细微指针视差与可见区域内的静音参考视频。
- 全局动效暂停；系统减少动态效果时默认静态画面，保留手动播放。
- 三个人物、实时字幕编辑、三种字幕样式、播放暂停和进度拖动。
- 四个创作阶段可点击、按下一步或通过键盘方向键切换。
- 原生 FAQ 折叠；主要行动直接跳转 GitHub，问题入口前往 Issues。
- 无邮箱申请表、无表单提交，不执行在线生成。人物片段是现有预设参考素材。

## 文件

| 文件                   | 用途                                         |
| ---------------------- | -------------------------------------------- |
| `index.html`           | 页面内容、语义结构、链接和 SVG 图标          |
| `styles.css`           | 响应式视觉系统与动效                         |
| `app.js`               | 媒体与交互状态                               |
| `assets/`              | 人物片段、海报、标志和字体；来源见本目录说明 |
| `DESIGN.md`            | 可复用设计规范                               |
| `tools/serve.mjs`      | 本地静态预览服务                             |
| `tools/fetch-font.mjs` | 按页面和脚本中文字符再生成字体子集           |

修改中文文案后运行 `node tools/fetch-font.mjs`。字体平时从本地加载，访客无需请求 Google Fonts。

## GitHub Pages

项目根目录运行 `npm run build:website` 生成 `_site/`，只复制官网公共文件；设计文档、本地工具和后端不会进入发布产物。打包脚本要求输出目录为空。

推送到 `main` 且涉及官网时，[发布工作流](../.github/workflows/pages.yml) 自动部署到 GitHub Pages。静态资源使用相对路径，支持 `/Szr3/` 项目子路径。无需配置自定义域名。
