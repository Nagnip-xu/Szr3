## 续租 GPU 后测试清单

1. 确认三个 Docker 容器 Running
2. `api/.env` 中 `GPU_SSH_PASSWORD` 正确
3. 启动 API，日志应出现 `Duix SSH 隧道已就绪`
4. 在「音频生成」面板上传 10–30 秒参考音频并训练自定义音色，或运行 `npm run bootstrap:voice`
5. 走完整流程：解析 → 配音 → 数字人 → 包装 → 导出
